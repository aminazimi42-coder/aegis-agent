# Aegis Agent Platform

A structured multi-agent platform with four specialist agents: Alina, Kiyan, Bita, and Aylin.

## Project structure

- `agents/` contains the four dedicated agents.
- `app/` contains the application runtime and orchestration layer.
- `core/` contains shared protocols, types, and registry definitions.
- `docs/` contains the phased roadmap and validation reports.

## Phase status

- Phase 0: foundation and constraints established
- Phase 1: core architecture and agent skeleton created
